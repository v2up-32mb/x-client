X Client — это высокопроизводительный многопротокольный VPN-клиент для Android. Каждый профиль конфигурации может индивидуально использовать выбранный протокол прокси, используя общую надежную платформу VPN-туннелирования, систему выбора оптимальных транзитных узлов, правила обхода маршрутизации и глобальные настройки.

- **Многопротокольная архитектура**: Развитие и глубокая переработка [gcm-client](https://github.com/v2up-32mb/gcm-client) с поддержкой трех протоколов: GCM, X-Tunnel и SOCKS5 (GCM и X-Tunnel — для шифрованного туннелирования через WebSocket; SOCKS5 — для прямого подключения к существующему вышестоящему SOCKS5-серверу с опциональной авторизацией по логину/паролю, TCP-ретрансляцией и локальным обходом маршрутов).
- **Сетевое ядро на Go**: Основной сетевой стек написан на языке Go (`golib/`, модуль `xclient`) и компилируется в нативную библиотеку `xclient.aar` с помощью `gomobile bind`.
- **Эффективное TUN-перенаправление**: VPN-туннель построен на базе легковесного [hev-socks5-tunnel](https://github.com/heiher/hev-socks5-tunnel), перенаправляющего TUN-трафик в локальный SOCKS5-прокси с околонативной скоростью.

## Возможности

- **Поддержка нескольких протоколов**: Протоколы **GCM**, **X-Tunnel** и **SOCKS5** сосуществуют независимо для каждого профиля; SOCKS5 позволяет напрямую подключаться к вышестоящему SOCKS5-серверу с опциональной аутентификацией (логин/пароль), TCP-ретрансляцией и локальным обходом маршрутов.
- **Полная локализация (i18n)**:
  - Доступны 4 языка: **Русский**, **English**, **简体中文** (упрощенный китайский), **繁體中文** (традиционный китайский);
  - Автоматическое определение языка системы с откатом на английский для непереведенных языков;
  - Мгновенное переключение языка в глобальных настройках без перезапуска приложения.
- **Глобальная система оптимальных транзитных IP**:
  - **Разнообразные источники**: Интеллектуальная выборка из официальных подсетей Cloudflare IPv4/IPv6 CIDR, подписка на сторонние списки и пакетный импорт из буфера/TXT;
  - **Проверка на реальном профиле**: Тестирование рукопожатия и обновления WebSocket на актуальном целевом сервере вместо поверхностных HTTPS-проверок;
  - **Легковесный учет измерений**: Тест скорости до 10 секунд (до 50 МБ на узел) с контролем бюджета раундов и проверками безопасности;
  - **Адаптивное переопределение**: Удобное переключение между режимами «Следовать глобальным» и «Индивидуальная конфигурация».
- **Защита от блокировок ECH + DoH**:
  - Трехуровневая отказоустойчивая система: DoH Fallback → UDP DNS (8.8.8.8:53) → Стандартный TLS 1.3;
  - Полное предотвращение цензуры и перехвата на основе SNI.
- **Высокопроизводительный пул соединений**:
  - Мультиплексирование соединений WebSocket и динамическое масштабирование пула;
  - Взвешенная оценка задержки транзитных узлов (Relay) и балансировка нагрузки;
  - Мониторинг качества соединения и автоматическое бесшовное переподключение.
- **Тонкая настройка маршрутизации и обхода**:
  - Прямой доступ к локальным и приватным адресам LAN;
  - Встроенные списки прямого доступа GeoIP:CN и GeoSite:CN;
  - Пользовательские правила для доменов и подсетей CIDR, а также правила принудительного проксирования.
- **Раздельное туннелирование по приложениям (Per-App Proxy)**:
  - Выбор приложений для перенаправления через VPN с удобным поиском и быстрым переключением.
- **Тест задержки прокси**:
  - Встроенный инструмент проверки задержки с настраиваемым URL (по умолчанию `gstatic 204`) и интервалом.
- **Современный интерфейс Material 3**:
  - 3 цветовые схемы («Кибераврора», «Титановый минимализм», «Швейцарский щит») с раздельным сохранением палитры для светлой и темной тем;
  - Интерактивная плавающая кнопка подключения (Connection FAB) с 5 состояниями и разворачиваемой карточкой с бегущей строкой;
  - Вторичное всплывающее меню карточки профиля (Переключить / Изменить / Поделиться / Копировать / Удалить) и информативные пустые состояния;
  - Динамическое отображение версии ядра Go в разделе настроек «О приложении».
- **Адаптация для Android TV и альбомной ориентации**:
  - Отсутствие обязательных аппаратных требований к сенсорному экрану и камере (`required="false"`), а также выделенный баннер для Android TV (`LEANBACK_LAUNCHER`);
  - Быстрое переключение VPN кнопкой D-pad / OK, контекстное меню по длительному нажатию пульта и полная навигация фокусом с визуальной подсветкой;
  - Многоколоночная сетка в альбомной ориентации и корректные безопасные отступы (edge-to-edge safe insets) для вырезов и широких экранов.
- **Обновление внутри приложения (In-App Update)**:
  - Проверка новых версий на GitHub Releases и загрузка APK под архитектуру (ABI) устройства с учетом маршрутизации VPN (трафик направляется через локальный SOCKS5-прокси при активном VPN);
  - Автоматическая очистка ранее загруженных APK-файлов обновлений.
- **Диагностика и журнал работы**:
  - Кольцевой буфер в памяти, время записей синхронизировано с часовым поясом системы Android;
  - 4 уровня подробности (Отладка, Информация, Предупреждение, Ошибка) и быстрый экспорт.

## Сравнение протоколов

| Параметр | Протокол GCM | Протокол X-Tunnel | Протокол SOCKS5 |
|---|---|---|---|
| **Заголовок пакета** | 2 байта (`[STREAM_ID:1][TYPE:1]`) | 8 байтов (`connID` + `msgType`) | Стандартный SOCKS5 (RFC 1928 / RFC 1929) |
| **Мультиплексирование** | 256 потоков на WS-соединение | Индивидуальное пространство `connID` для канала | Прямой исходящий TCP-вызов по запросу (1:1 на соединение) |
| **Выбор маршрута** | Оценка транзитных узлов + балансировка | Гонка каналов + Hot Pair (горячий резерв) | Прямое подключение к upstream; опциональная авторизация логин/пароль |
| **Пересылка UDP** | Не поддерживается | Полная поддержка SOCKS5 UDP associate | Не поддерживается в фазе 1 (возвращает `0x07`) |
| **HTTP-прокси** | Внутри туннельного потока | Отдельный локальный прослушиватель HTTP-прокси | Без отдельного HTTP-прослушивателя |
| **Обход маршрутизации** | ✅ Поддерживается (LAN/GeoIP/GeoSite/Свои) | ✅ Поддерживается (прямой обход для SOCKS5/HTTP) | ✅ Поддерживается (LAN/GeoIP/GeoSite/Свои/Force-proxy) |
| **ECH / DoH** | ✅ Общий защитный модуль на Go | ✅ Общий защитный модуль на Go | Не используется (прямое подключение к upstream) |

## Форматы конфигурации и URI

X Client поддерживает импорт профилей через QR-код или буфер обмена:

### Ссылка протокола GCM
```
gcm://<workerHost>?ip=<транзитныйIP:порт>&fip=<выходнойIP>&user_id=<userID>&dns=<DoHсервер>&domain=<доменECH>&disable_ech=1#<ИмяПрофиля>
```

### Ссылка протокола X-Tunnel
```
xtunnel://<serverAddr>?token=<токен>&relay_nodes=<узлы>&connections=<число>&ech=0|1&domain=<доменECH>&dns=<DoHсервер>&insecure=1&hotpair=<пары1-8>&ips=<стратегия>#<ИмяПрофиля>
```

### Ссылка протокола SOCKS5
```
socks5://[username[:password]@]host:port#<ИмяПрофиля>
```

- **Обратная совместимость**: Ссылки `ech://` по-прежнему поддерживаются для GCM; при импорте профилей SOCKS5 также поддерживается схема `socks://`;
- **Разбор SOCKS5**: Поддерживается формат IPv6 `[host]:port`; если порт не указан, используется `1080` по умолчанию;
- **Hot Pair**: `hotpair=1` (или `true`) включает 1 пару резервных каналов; `hotpair=2..8` включает несколько пар;
- **Стратегия IP**: Поддерживаются режимы `IPv4,IPv6` (по умолчанию), `IPv6,IPv4`, `IPv4` и `IPv6`.

```

├── app/                  # Исходный код Android (Java 17, Material 3, VpnService)

│   │   ├── LanguageManager.java          # Динамическое применение языков

│   │   ├── TvFocusHelper.java            # Подсветка фокуса D-pad для Android TV
│   │   ├── UpdateManager.java            # Проверка GitHub Release, загрузка и очистка
│   │   └── ...
│   ├── src/main/res/                     # Ресурсы интерфейса
│   │   ├── values/                       # Базовые ресурсы (English)
│   │   ├── values-zh-rCN/                # Упрощенный китайский (简体中文)
│   │   ├── values-zh-rTW/                # Традиционный китайский (繁體中文)
│   │   ├── values-ru/                    # Русский язык
│   │   └── ...
│   └── libs/xclient.aar  # Скомпилированный бинарный модуль gomobile (генерируется в CI)
├── golib/                # Ядро на Go (модуль xclient, Go 1.27)
│   ├── android.go        # Точка входа gomobile и диспетчеризация протоколов
│   ├── gcm/              # Адаптер бэкенда GCM (сборка gcmlib и правила обхода)
│   ├── xtunnel/          # Адаптер бэкенда X-Tunnel (сборка xtlib и правила обхода)
│   ├── socks5/           # Бэкенд SOCKS5 (TCP-ретрансляция RFC 1928/1929 и обход)
│   └── ipopt/            # Алгоритмы оптимальных IP, зондирование и сканер подсетей
│   # Прим.: общие модули (config, dialer, dns, ech, httpproxy, logger, pipe, routing, socks5)
│   # подключаются из внешней библиотеки github.com/v2up-32mb/xshared
└── .github/workflows/    # Конвейеры CI (кэширование AAR, сборка, подпись и релиз)
```

### Схема прохождения трафика

```
[ Трафик приложений (App Traffic) ]
                 │
                 ▼
[ Устройство TUN Android VpnService ]
                 │
                 ▼
[ hev-socks5-tunnel (C / JNI) ]
                 │ (Преобразование пакетов TUN в SOCKS5)
                 ▼
[ Локальный SOCKS5-прокси (Go / golib слушает 127.0.0.1:1080) ]
       │                                      │
       ├─ [ Правило прямого обхода (Bypass) ] └─ [ Диспетчер бэкенда (Proxy Dispatch) ]
       │        │                                    ├──▶ [ GCM / X-Tunnel ] ──▶ [ ECH / TLS 1.3 ] ──▶ [ Сервер / Worker ]
       ▼        ▼                                    └──▶ [ SOCKS5 ] ──────────▶ [ Вышестоящий SOCKS5-прокси ]
  [ Прямой узел назначения ]
```

## Сборка и разработка

> **Ограничение сборки**: Сборка и подпись релизных APK выполняются в GitHub Actions. Локально проводятся только модульные тесты ядра Go.

### Запуск модульных тестов ядра Go

```bash
cd golib
# Запуск всех тестов ядра с проверкой состояния гонки
CGO_ENABLED=1 go test -race -count=1 ./...
```

### Автоматизация в GitHub Actions

- **Кэширование AAR (`build-aar.yml`)**: Срабатывает при коммитах в `golib/**` ветки `main` (или вручную), собирая и кэшируя `xclient.aar`.
- **Релизы и CI-проверка (`release.yml`)**:
  - **По тегу (`v*`)**: Собирает, выравнивает и подписывает Release APK для всех архитектур ABI и автоматически создает GitHub Release (теги с суффиксами `-preview`, `-beta` или `-rc` помечаются как pre-release).
  - **Ручной запуск (`workflow_dispatch`)**: Запускает Go-тесты с `-race`, проверки `gomobile`/API и собирает подписанный `com.x.client.app.debug` APK (`ci-<shortsha>`), который можно установить параллельно с релизной версией для тестирования без публикации релиза.
